# 第 5 章 · 屏幕小程序：AI 的手和眼

> 这一章做完：电脑上常驻一个小程序，AI 通过它截图、点、打字，屏幕底下会出它的字幕；你在手机上能按「我来」叫它停手。
> 目前只走通过 Windows。Mac 版写了没测过，见本章最后。

它是三样东西：

| | 干嘛的 |
|---|---|
| `server.mjs`（Node） | 主程序，开两扇门（见下） |
| `hand/hand.exe` | 截图、动鼠标键盘、认出「是不是人在碰」、把窗拎到前面 |
| `hand/overlay.exe` | 屏幕最上面那层：字幕、点下去的那一圈。CrossDesk 抓屏不带光标，所以 AI 点哪儿得自己画出来 |

两扇门：

| 门 | 谁来敲 | 能干嘛 |
|---|---|---|
| `127.0.0.1:5260` | 只认本机。本地 Agent（第 6 章）从这儿进 | 截图、动手、字幕、记账 |
| `127.0.0.1:5261` | 经隧道接到 VPS 上（本章第 5 步） | 看状态、按「我来」、配对码换钥匙、连接器转来的工具调用（第 7 章） |

---

## 1. 要准备的

- Windows 10 或 11
- [Node.js](https://nodejs.org/) 18 以上（我们用的是 24）
- 编 `hand.exe`、`overlay.exe` 用 Windows 自带的 .NET Framework 4 编译器，不用另装

## 2. 编两只手

在仓库的 `hand` 目录里打开 PowerShell：

```powershell
$csc = "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe"
& $csc /nologo /target:exe /r:System.Drawing.dll /out:hand-v2.exe hand.cs
& $csc /nologo /target:winexe /r:System.Drawing.dll /r:System.Windows.Forms.dll /out:overlay.exe overlay.cs
```

（`hand-v2.exe` 这个名字是 `server.mjs` 认的，别改。）

## 3. 钥匙：deploy/door.json

第 3 章生成过两把，这里再加一把给第 7 章的连接器用：

```json
{
  "h": "<门牌>",
  "w": "<钥匙>",
  "g": "<连接器钥匙>"
}
```

`g` 照样拿 `openssl rand -hex 16` 生成，或者在 PowerShell 里：`-join ((1..16) | % { '{0:x2}' -f (Get-Random -Max 256) })`。

还要有第 4 章那份 `deploy/site.json`，小程序靠它认外面来的请求是不是你的域名。

## 4. 起它

```powershell
cd <仓库目录>
node server.mjs
```

另开一个窗口验：

```powershell
Invoke-RestMethod http://127.0.0.1:5260/agent/live
```

回一串状态（`status`、`hold` 之类）就对了。试一下字幕：

```powershell
Invoke-RestMethod http://127.0.0.1:5260/agent/say -Method Post -ContentType 'application/json' -Body '{"s":"你好","quiet":true}'
```

屏幕底下正中出来一行「你好」＝两只手都活着。

**一开始「我来」是按着的**（AI 什么都动不了），要你自己放开一次，见第 6 章。

### 不弹窗、开机自己起

直接 `node server.mjs` 会留一扇黑窗口，关了它就停。仓库里的 `start.vbs` 是不弹窗的起法；让它登录时自己起，建一个计划任务：

```powershell
$a = New-ScheduledTaskAction -Execute 'wscript.exe' -Argument '"<仓库目录>\start.vbs"' -WorkingDirectory '<仓库目录>'
$t = New-ScheduledTaskTrigger -AtLogOn -User "$env:USERDOMAIN\$env:USERNAME"
$s = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit (New-TimeSpan -Minutes 1)
Register-ScheduledTask -TaskName 'ScreenHands' -Action $a -Trigger $t -Settings $s
```

> 要在**你登录着的那个桌面**里起，它才截得到屏、动得了鼠标。别装成系统服务。
> 我们家写这一章时才发现自己一直没装这一条，是手动起的，写完当场补上了。

## 5. 隧道：让 VPS 够得着家里那扇 5261

用 [frp](https://github.com/fatedier/frp/releases)。VPS 上跑 frps，电脑上跑 frpc，电脑主动往外连，家里不用开任何口。

**VPS 上**（frp 的 Linux 包，`frps` 放 `/opt/frp/`）：

`/etc/frp/frps.toml`：

```toml
bindPort = 7000
auth.token = "<隧道口令>"
transport.tcpMux = true
transport.heartbeatTimeout = 45
# 映射出来的口只给本机 Caddy 用，不对外
proxyBindAddr = "127.0.0.1"
```

照第 1 章那样写一份 systemd 服务（`ExecStart=/opt/frp/frps -c /etc/frp/frps.toml`），起它。**防火墙要多开一个 7000/tcp**，电脑从这儿连进来。

**电脑上**（frp 的 Windows 包，`frpc.exe`）：

`frpc-screen.toml`：

```toml
serverAddr = "<VPS 的 IP>"
serverPort = 7000
auth.token = "<隧道口令>"
loginFailExit = false
transport.tcpMux = true
transport.heartbeatInterval = 15
transport.heartbeatTimeout = 45

[[proxies]]
name = "screen-console"
type = "tcp"
localIP = "127.0.0.1"
localPort = 5261
remotePort = 39260
```

> **别让 frpc 继承代理。** 我们家有一回它从环境里继承了一个本机代理，代理一关它就连不上，断了整整一天没人发现。用计划任务起（计划任务不带你终端里的代理变量），再配一个每 5 分钟看一眼的看门任务：从外面敲一下，连着两回敲不开就重起它。仓库里 `tools/watch-frpc-screen.ps1` 就是这个，文件开头写着怎么装成计划任务；先加 `-DryRun` 跑一回，看它打算怎么做、什么都不动。

**Caddy**：在第 3 章那段里、`handle {` 之前加：

```caddy
	# 连接器转来的工具调用只许 VPS 本机进，外面来的一律挡
	handle /api/agent/remote* {
		respond 403
	}
	handle /api/agent/* {
		reverse_proxy 127.0.0.1:39260 {
			transport http {
				dial_timeout 8s
			}
		}
	}
```

## 6. 验

```
https://<你的域名>/api/agent/card-control
```

浏览器打开，回 `{"error":"POST required"}`（405）＝ VPS → 隧道 → 家里这条通了。回 502＝隧道没连上，看 frpc 的日志。

## 7. 头一个配对码

「新设备的码」要一台已经进过门的设备才发得出来。头一回谁都没进过，就在电脑上要：

```powershell
Invoke-RestMethod http://127.0.0.1:5260/agent/paircode
```

回一个六位数，十分钟有效。手机打开 `https://<你的域名>/`，在配对码那格填它，这台手机就进门了。以后别的设备要进门，由进过门的设备给码（第 4 章说的那颗按钮）。

## Mac

`hand/hand-mac.swift`、`hand/overlay-mac.swift` 是照 Windows 版一样样对着写的 mac 版，`server.mjs` 在 mac 上会自己换用它们。**写了，但没编译过、没在 mac 上跑过。**

- 要 macOS 14 以上
- 编：`xcode-select --install`，然后 `sh hand/build-mac.sh`
- 系统设置 → 隐私与安全性，给拉起它的程序（终端或 node）开三样：屏幕录制、辅助功能、输入监控
- 坐标用的是「点」，不是像素
- 开机自启要写一份 launchd 的 plist（待写）

有 mac 的人走一遍，最好。
