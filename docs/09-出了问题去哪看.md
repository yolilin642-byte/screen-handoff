# 第 9 章 · 出了问题去哪看

> 先分清是哪一截断了，再去那一截的日志里找。下面那张「常见的样子」，全是我们家真撞过的。

---

## 1. 从外往里敲五下

一截一截往里敲，头一个不对的就是断的那截：

| 敲 | 应该 | 不对的话，坏在 |
|---|---|---|
| 浏览器开 `https://<你的域名>/stats` | 一串数字 | VPS、Caddy、证书、信令（第 1 章） |
| 浏览器开 `https://<你的域名>/door?k=<钥匙>` | 一片空白（204） | 门、钥匙抄错（第 3 章） |
| 浏览器开 `https://<你的域名>/api/agent/card-control` | `{"error":"POST required"}` | 隧道，或者家里的小程序没起（第 5 章） |
| 浏览器开 `https://<你的域名>/.well-known/oauth-protected-resource` | 一段 JSON | 连接器（第 7 章，没装就跳过） |
| `node tools/turn-check.cjs` | `TURN allocate OK` | 中继（第 8 章，没装就跳过） |

电脑本机上再看两样：

```powershell
Invoke-RestMethod http://127.0.0.1:5260/agent/live | Select-Object status, hold, guardReady
Invoke-RestMethod http://127.0.0.1:19825/kael-guard -Headers @{ 'X-OpenCLI' = '1' }
```

- 第一行：小程序活着。`hold` 是 `True`＝「我来」按着；`guardReady` 是 `False`＝OpenCLI 那道闸没装上或者守护进程没起。
- 第二行：回 `guard: 1`＝OpenCLI 的闸在。

> **`/agent/live` 回来的东西里带着门钥匙**（本机的聊天页要用）。上面只挑了三格看；整份别截图、别贴给任何人，报 bug 也别贴。

## 2. 日志在哪

| 哪一截 | 在哪看 |
|---|---|
| CrossDesk 主机端 | 程序目录下 `logs\crossdesk.log`（连没连上服务器、谁连进来、断开）、`logs\minirtc.log`（画面、编码、网络，很长） |
| 屏幕小程序 | 仓库 `log\events.jsonl`：每一下动手、每一回被挡、配对、远程 AI 的每一下都在这儿。`log\jobs.jsonl`、`log\steps.jsonl` 是每趟活的账 |
| 隧道（电脑那头） | `frpc-screen.toml` 里 `log.to` 写的那个文件；看门任务自己的账在它旁边的 `frpc-screen-watch.log` |
| 信令 | VPS 上 `sudo journalctl -u crossdesk -n 100` |
| Caddy | `sudo journalctl -u caddy -n 100` |
| 隧道（VPS 那头） | `sudo journalctl -u frps -n 100` |
| 连接器 | `sudo journalctl -u screen-connector -n 50`；它目录下 `calls.jsonl`（远程 AI 每一下调了什么、有没有被拒）、`reports.jsonl`（直播卡报回来的：连没连上、卡在哪、外层是谁） |
| 中继 | 中继那台上 `sudo docker logs coturn --tail 50` |
| 手机上的网页 | 小屏、直播卡顶上那行字本身就是状态：「连接中…」「要密码」「门上了锁」「直播中 · 1808×1130 · 30帧 · direct」 |

## 3. 常见的样子

### 连不上、白屏

| 样子 | 多半是 | 怎么办 |
|---|---|---|
| 操控台一直「家里没回音」，`/api/agent/*` 回 502 | 隧道断了 | 看 frpc 的日志。我们家撞过两种：一种是 frpc 从终端里继承了一个代理，代理一关它就连不上；一种是进程活着，每 30 秒重登一回、回回超时（假活）。都是杀了重起就好，所以要配看门任务（第 5 章） |
| 什么都 403 | 钥匙不对、这台设备没配过对 | 网页会摆出配对码那格，去进过门的设备点「新设备的码」 |
| 电脑上 CrossDesk 说没连上服务器 | 还在走老地址、版本太老 | 服务器地址要带 `/h/<门牌>`；要 v1.7.4 以上（第 3 章） |
| 刚改完 Caddy，电脑就掉线了 | 第 3 章挂门那一下 | 正常，把 CrossDesk 的地址换成门牌那条就好 |
| 网页一直停在旧样子 | 手机拿的是缓存里的旧页 | 第 4 章给首页和两个小脚本加了 `no-cache`；没加的话旧首页会配上新脚本，认不出外层 |
| 电脑开着代理／VPN，画面连不上 | CrossDesk 的流量被代理绕走了 | 把 `CrossDesk.exe` 和 `frpc` 排除在代理外面（我们家用 Mullvad，在它的分流里排除） |
| 公共网络、手机流量下连不上，家里 Wi-Fi 能连 | 直连打不通，又没有中继 | 第 8 章 |

### 连上了，但是

| 样子 | 多半是 | 怎么办 |
|---|---|---|
| 「密码不对」 | CrossDesk 的密码，不是门钥匙 | 看电脑上 CrossDesk 窗口里那个 |
| 卡、糊 | 网页默认「画质优先」，网一紧就掉帧守分辨率 | 我们改过的网页连上以后自己换成「帧率优先」。还卡就看小屏报的 `kbps`、`loss`、`rtt` |
| 一断开电脑就锁屏，AI 干不了活 | CrossDesk 的「断开时锁屏」开着 | 第 2 章：设置里关掉（`lock_on_disconnect=false`） |
| 弹出 UAC（要管理员的那个框）、锁屏以后，什么都看不见、点不了 | CrossDesk 没装它的系统服务，碰不到那一层 | 这是已知的限制：人到电脑前去点。装 CrossDesk Service 能解决，要管理员，我们家没装 |
| 要扫码登录 | 二维码在你手机上，同一台手机扫不了它自己 | 截图从相册识别，或者换账号密码、短信登录 |

### AI 那头

| 样子 | 多半是 | 怎么办 |
|---|---|---|
| AI 说「你按着我来」「The user is holding control」 | 「我来」按着 | 按「还给你」 |
| AI 说「你在用」「The user is using the computer right now」 | 你四秒内碰过鼠标键盘 | 手离开，等一下。从 CrossDesk 里点画面也算你在碰 |
| 字幕写「动作结果不确定，已停手」 | 一条命令超时了，不知道它到底做没做 | 看一眼屏幕，确认没事按「还给你」。不用重起任何东西 |
| 「我来」按着，OpenCLI 照样在点网页 | OpenCLI 升级了，那道闸被冲掉 | 第 6 章第 2 步重装；这时 `guardReady` 会是 `False`，小程序也不会说「你接手了」 |
| AI 点歪了 | 截图是缩过的 | 点的时候要把截图回来的 `scale` 带上，小程序替它换回屏幕坐标（说明书里写了） |
| 官端 AI 用 `screen_click` 点歪了 | 它是看图估的坐标 | 网页上的活让它用 `browser_*`（按编号点）；桌面上点歪了，让它再看一眼再点 |
| 远程 AI 开的 Chrome 窗一直开着 | 它不爱关 | 十分钟没碰家里自己关（第 7 章） |
| 「The previous action is still running」 | AI 上一下还没做完 | 一次只做一件，等它 |

### 配对、授权

| 样子 | 多半是 | 怎么办 |
|---|---|---|
| 「配对码过期了」 | 十分钟到了、用过了、错了五回 | 再要一个。新的会顶掉旧的 |
| 授权页说「家里没回音」 | 连接器够不着家：隧道断了，或者 `relay.key` 跟 `g` 不一样 | 第 7 章第 5 步那条 `curl` |
| desk 门回 404 | 门关着：`door.json` 没有 `d`，或者 `d` 不到 16 位字母数字 | 第 6 章最后一节第 1 步 |
| desk 门回 403 | 钥匙不对，或者是从域名进来的（只认 VPS 本机敲 39260）；`events.jsonl` 里 `desk-refused` 那行的 `why` 写着是哪样 | 在 VPS 上敲 `127.0.0.1:39260`，别敲域名 |
| 直播卡「电脑那页没认出这个框」 | 外层没登记 | 第 7 章第 8 步，翻 `reports.jsonl` 抄进 `cardOrigins` |

## 4. 还没查明白的

照实列着，碰到了别以为是自己装错了：

- **画面一卡一卡、主机端编码器反复重起**：我们家见过一回，五分钟里 Media Foundation 编码器重起了 51 回，信令那头同时在报收队列满。换成帧率优先以后没再见，原因没吃透。
- **App 外壳里拉图比 Chrome 慢**：我们自己聊天页的手机外壳里，同一张图比 Chrome 慢好几秒，原因没查。只有把小屏嵌进 App 外壳的人会碰到。
- **「活着但连不上」的隧道**：看门任务能接回「进程没了」和「敲不开」，进程活着、偶尔敲得开、大多数时候连不上的那种，没模拟过。
