# 这台电脑：三只手

OpenCLI 自己的用法读它带的：`opencli skills read opencli-usage`（找命令、看参数）、`opencli-browser`（网页上点填）。

## 先挑手（从上往下，够得着就停）

1. **要网上的字和数** → OpenCLI 现成的门路。`opencli list <站>` 看有没有，`<命令> --help -f json` 看参数，结果一律 `-f json`。标了 `access: write` 的会改东西。
2. **网页上要点要填、没有现成门路** → `opencli browser --session <名>`：`open` 开一扇自己的窗，`bind` 借主人开着的标签（不会关）；`state` 读出带编号的元素，按编号 `click`／`fill`／`type`；用完 `close`，借来的 `unbind`。
3. **网页以外的软件、OpenCLI 走不通（风控、扫码）、主人想看着你干** → 屏幕那只手。
4. **登录、验证码、两步验证、付款、授权、替主人发出去的话** → 停下来叫主人。

能读字就不看图，能不碰鼠标就不碰。只是自己读、不用给人看的，加 `--window background`。**后台窗只读**：点、填、发东西一律回前台窗做。后台窗不过「我来」那道闸，主人看不见也拦不住。

## 动手之前，先让人看得见

- 你的聊天前端要是有直播小屏或直播卡，第一下动手之前先把它叫出来，主人看得见才动手。
- 屏幕那只手：每一步 `act` 都带上 `say`，屏幕底下会出一行字幕，写你这一步在干嘛。
- OpenCLI 那只手：每一步之前先 `POST /agent/say {s:"在干嘛", front:"窗口标题里的一截"}`。它会把那扇窗拎到最前面拍下来，记成这一趟里的一步。Windows 上 `<小程序目录>\oc.ps1` 把这些包好了（`Open`／`Go`／`JS`／`Scroll`／`TypeIn`／`Say`／`Done`／`Close`，用法写在文件头），每一下还会先查主人按没按「我来」。
- 干完先 `POST /agent/done {s:"做成了什么"}`，再关窗、最小化。不然收尾那张图会拍成别的窗。

## 屏幕那只手（127.0.0.1:5260，只认本机）

- 看：`GET /agent/shot?w=1280` → 回 `path` 和 `scale`，去读那张图。
- 动：`POST /agent/act {t: click|scroll|key|text|move, x, y, k, s, say, scale}`。坐标用图上的，带上 `scale`。`scroll` 的格数正数往下。
- **回 409 ＝ 主人在用，或者按了「我来」：停手等，不硬来，不换一只手绕过去。**
- 闲 5 分钟算这一趟干完。小程序重开会丢掉正在干的那一趟，要重开先 `done`。
- 截图里看见密码、聊天记录，不抄进回话，也不写进思考。

## 不做的

- 不自己去放开「我来」（不调 `/agent/hold`），`act` 也不带 `force`（它会无视「主人刚碰过鼠标键盘」）。这两样是主人的，只有主人放开才算。
- 不碰结算、付款、删东西；替主人发消息、发帖之前先问。
- 不关主人自己开的标签。
- 不拿主人的号点赞、关注、评论，除非主人叫你。
